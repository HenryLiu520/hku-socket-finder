# 九十秒導覽

*這是甚麼，按讀者遇見它的次序。*

## 問題，一句話

你走進一間研習室，坐下，打開筆記型電腦，插上電——甚麼都沒發生。插座是壞的，而桌子、門口或大學自己的系統，都沒有在你坐下之前告訴你。

## 單位是插座，不是房間

訂位系統數房間。報修系統數故障。兩者都不回答你真正有的那個問題，那個問題關於你眼前的桌子。一間房間可以是「可用」，而裡面唯一空著的桌子可以毫無用處，所以 Sure Socket 給每個插座自己的身分：

```
CPD-LG01-0001     樓 · 房間 · 四位位置
```

號碼只分配一次，永不重用。學生把它說出口，職員在隊列裡讀到同一個字串，而資料庫不允許兩個插座用同一個號碼——號碼是所有人爭論的那件事，所以它在任何地方都必須是同一件事。

## 產品圍繞的三個時刻

1. **找。** 選一棟樓，選一個房間，看到每個插座按最後一次已知狀態上色，旁邊有上次核查的日期。房間的平面圖把顏色放在它們所屬的桌子上，所以你可以看著桌子，而不是看著一份清單。
2. **報告。** 四個選擇——樓、房間、插座號碼、哪裡壞了——而從一個已打開的房間出發只需要三下。插座當場變色，所以你看得到自己的報告落了地。
3. **維修。** 職員得到一條隊列，按最舊的核查優先排序，每一行旁邊有它背後的帳號數目。關閉一項維修會蓋上時間，房間顯示新狀態，下一個學生讀到它。

![房間平面圖：每個插座一個顏色方塊，標上它的號碼](screens/mobile/05-phone-room.jpg)

## 評審最先看到甚麼

房間選擇頁：四棟樓、樓下的房間，以及每個房間裡正常、鬆脫、壞掉和未核查插座的數目。按一下，一個陌生人就在看某個房間、某個樓層，某個插座被標成紅色——點一下示範帳號即可進入、不用設定、不需解釋。
